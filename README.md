# CDAZZDEV-MLE-Dinuka

Technical assessment submission for the **Senior Machine Learning Engineer** role at **Ceylon Dazzling Dev Holding (Pvt.) Ltd.**

## Assessment Tasks

This repository contains implementations for the three assessment areas:

- `task1_financial/` — Financial AI
- `task2_genai/` — Generative AI
- `task3_agentic/` — Agentic Workflows

## Task 3 — Agentic Workflows

Task 3 focuses on building a multi-agent financial research system with:

- Tool-using research agents
- Financial market data analysis
- News retrieval
- LLM-based sentiment analysis
- Web search
- Short-term and persistent memory
- Agent observability and execution tracing

### Implemented Tools

The current Task 3 implementation includes:

- `get_price_data(ticker, period)`
- `get_news(ticker, n)`
- `calculate_volatility(ticker, window)`
- `llm_sentiment(headlines)`
- `web_search(query)`

The agent architecture and remaining Task 3 requirements will be implemented incrementally.
